# 世界观维度清单（背景设定 / 力量体系 / 地理）

每个条目五段式：条目名 + 描述 + 影响/约束 + 冲突/伏笔潜力 + 与其它条目的引用。

## 背景设定类

- 时代与文明阶段：当前时代名称、科技/生产力水平、与历史断层的关系。
- 历史主线：三次以内改变世界格局的大事件（事件名、参与方、结局、遗留问题）。
- 社会结构：阶层划分、上升通道、边缘群体；谁制定规则、谁被规则压制。
- 文化与信仰：主流信仰/禁忌、仪式、禁忌被触犯的后果（必须可执行，不写空话）。
- 经济与资源：核心 scarce 资源是什么、谁控制、分配机制如何制造矛盾。

## 力量体系类（防崩重点）

- 力量来源：修炼/血脉/科技/契约/外物——来源唯一还是并存，并存时换算关系。
- 等级阶梯：等级名、每级标志性能力、晋升条件、晋升失败代价（等级数量建议 ≤9）。
- 代价与限制：每次使用力量的成本（寿命/资源/心智/社会代价）；无代价的力量必须配外部制衡。
- 天花板与底牌：当前世界明面天花板、主角终局底牌预留位（只占位不展开，防写无可写）。
- 战力锚点：每个等级配一个参照物（某势力首领/某战役结果），跨文件引用到 `设定/势力/` 对应条目。

## 地理类

- 世界全貌：一句话总览 + 分区表（分区名、一句话特征、控制势力引用）。
- 关键地点：每个地点独立条目——位置、归属势力、资源/战略价值、发生过的大事件。
- 交通与阻隔：分区之间如何往来、天险/禁地在哪里、谁能通行谁不能（通行权即权力）。
- 气候与物产：影响战力与剧情的地理要素（禁魔区、资源矿、绝地），引用到力量体系条目。

## 条目写作模板

```md
## {条目名}

- 描述：{一句话定义 + 关键事实，不超过 5 行}
- 影响/约束：{它限制了谁、允许了谁；写正文时必须遵守什么}
- 冲突/伏笔潜力：{它天然制造什么矛盾、可埋什么伏笔，指向哪个势力/角色}
- 引用：{相关条目名 → 文件路径，如 战力天花板 → 设定/世界观/力量体系.md}
```
