# 势力卡模板（一势力一文件：`设定/势力/{势力名}.md`）

文件名即势力名。单个势力文件可含多张卡（主卡 + 附属组织），每张卡五段式。

```md
# {势力名}

## 基本盘

- 描述：{性质（宗门/世家/国家/商会/地下组织）、规模、总部位置 → 引用 设定/世界观/地理.md}
- 影响/约束：{它在世界中能调动什么资源、受谁节制}
- 冲突/伏笔潜力：{它与谁天然对立、可埋什么线}
- 引用：{相关地点/规则条目路径}

## 实力与底牌

- 明面实力：{最高战力等级 → 引用 设定/世界观/力量体系.md 的等级条目}
- 隐藏底牌：{占位即可，不展开；注明"终局前不揭晓"}
- 致命弱点：{至少一个可被对手利用的结构性弱点，无弱点的势力不允许存在}

## 诉求与行动逻辑

- 核心诉求：{它最想要什么，一句话}
- 行动红线：{它绝不做什么——供后续"出人意料但合理"反转用}
- 与主角线的接口：{招揽/打压/利用/无视，至少选一并写条件}

## 修订记录（YYYY-MM-DD）

- {改了什么、为什么改、影响哪些引用条目}
```
