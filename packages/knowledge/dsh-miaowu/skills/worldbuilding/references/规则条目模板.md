# 规则条目模板（一规则一文件：`设定/规则/{规则名}.md`）

规则/铁律是世界的硬约束：天道法则、契约代价、禁地戒律、组织铁律均属此类。
违反规则必须有可执行的代价，否则降级为背景描述，不配独立成条。

```md
# {规则名}

## {条目名}（一文件可多条，每条独立成节）

- 描述：{规则原文（一句话）+ 适用范围（对谁、在哪生效）}
- 影响/约束：{遵守者得什么、违反者付什么代价；代价必须具体（等级跌落/寿命/资源/社会性死亡选一以上）}
- 冲突/伏笔潜力：{主角何时会撞上这条规则、是否存在可钻的空子（空子本身也是伏笔）}
- 引用：{支撑该规则的力量体系/势力条目路径}
- 执行记录：{正文中第几次触发、结果如何（写正文后回填，建世界时留空表）}

## 修订记录（YYYY-MM-DD）

- {改了什么、为什么改、影响哪些引用条目。铁律修订必须同步检查所有引用它的势力卡与力量体系条目}
```
