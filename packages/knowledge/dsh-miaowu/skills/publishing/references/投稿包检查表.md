# 投稿包检查表

> `publishing` 工作流第 1-2 节使用。逐项勾选，未通过项阻塞投稿包组装。

## 1. 平台选择（每个候选平台一行）

| 平台 | 目标读者 | 题材样本（榜单/推荐位实例） | 核心指标 | 失败风险 |
|---|---|---|---|---|
| 例：番茄 | | | 完读率/追更 | AI 同质化 |
| | | | | |

- [ ] 长篇已核对 `publishing-guide.md`「平台选择与定位」（写法节奏/题材噱头/样本匹配度三方向）
- [ ] 短篇已核对 `submission-craft.md`「先定平台基调」（视角/矛盾演进/章末钩子/结局质感随平台切换）
- [ ] 合同/分成/独家条款以平台最新官方口径或编辑确认为准（本表不作收益承诺）

## 2. 待投正文核对

- [ ] 章节完整性：长篇正文章节编号连续、与 `大纲/` 卷纲细纲对应无缺章跳章；短篇全文累计字数已机器统计（非模型估算）
- [ ] 排版门禁：短篇通过 `short-format.md`「写完每段快速检查」；长篇样章与追踪已完结章节一致
- [ ] 连载状态声明明确（未发/连载中/已完结，全本/样章投递范围）
- [ ] 版权声明完整（原创声明或授权链文件齐备，一稿多投不违反独家约定）
- [ ] 内容合规自查通过（涉政/涉黄/暴力/抄袭红线；不合规先回炉，不送审）

## 3. 投稿包齐套（`{作品}/投稿包/{平台}_{YYYYMMDD}/`）

- [ ] `简介.md`（长篇：处境→金手指→爽点预览广告体；短篇另附 150-220 字导语）
- [ ] `大纲.md`（长篇全书梗概+阶段爽点；短篇一页梗概+付费点位置）
- [ ] `样章/`（平台要求篇幅，原样复制不改写；短篇标注付费点断点）
- [ ] `投稿说明.md`（笔名/联系方式/首发声明/更新计划）
